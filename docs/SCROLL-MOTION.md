# حركات الموقع والتحكم فيها

التنفيذ يستخدم IntersectionObserver وCSS transitions وواجهات المتصفح فقط. لم تُضف مكتبة أو dependency. محتوى الهيرو وصورة LCP يظهران فورًا. لا يحدث تعديل على DOM من محرك التمرير قبل أول scroll؛ وبعده تُجهّز العناصر القريبة فقط.

## التأثيرات

- الكروت تبدأ متداخلة، بإزاحة محسوبة لكل كارت، ودوران بين ‎-12° و‎+12°، وscale بقيمة 0.9 وopacity بقيمة 0.16. تتجمع خلال 900ms باستخدام `cubic-bezier(.22,1,.36,1)`.
- الأيقونات تتجمع من إزاحات متفرقة مع دوران وscale بقيمة 0.72، خلال 900ms.
- النصوص تدخل بـfade وtranslateY بقيمة 40px، مع تبادل الاتجاه الجانبي بين الأقسام وعكسه في RTL.
- العناوين الكبيرة تظهر سطرًا سطرًا. الكلمات الكاملة مجهّزة في HTML الأصلي بواسطة `HeadingWords`؛ محرك الحركة يقيس السطور ولا يكتب النصوص أو يعيد تقسيم DOM. مراقبة العنوان نفسه تحافظ على دخول كلمات كل سطر معًا. وسوم h1/h2/h3 ونصوصها وalt وmetadata محفوظة.
- الفاصل بين العناصر أو السطور المتجاورة 100ms، عبر `--i`، بحد أقصى 600ms للعناوين الطويلة.
- الصور في الأعمدة المجاورة تتحرك رأسيًا بسرعات مختلفة، بحد أقصى 12px. يعمل ذلك على الديسكتوب من 1024px مع hover وpointer دقيق، ويتوقف عند التحول لمقاس أصغر أو تقليل الحركة.
- hover يرفع الكروت 4px، ويحرّك الصورة 3px مع scale بقيمة 1.04 داخل إطار `overflow:hidden`. الظل ثابت عند hover ولا يُحرّك فريمًا بفريم.
- مؤشر الماوس هو مؤشر النظام الطبيعي. أزيل المؤشر الزخرفي والنقطة السوداء بطلب المالك.
- الإحصائيات مؤجلة باختيار المالك إلى حين توفير أرقام معتمدة. لم يُضف قسم إحصائيات أو أي رقم تسويقي.

## التحكم في السرعة والاتجاه والتأخير

عدّل القيم في `motionConfig.js` ثم شغّل build:

```js
revealDuration: 680, // النصوص: ms
cardDuration: 900,   // تجميع الكروت: ms
gatherDuration: 900, // تجميع الأيقونات: ms
stagger: 100,       // يُفضّل 80–120ms
maxStagger: 600,
distance: 40,       // دخول النص: px
cardScatter: 96,    // مجال تقارب الكروت نحو مركز المجموعة
scatter: 44,        // انتشار الأيقونات
parallax: 12,       // أقصى حركة خلفية/صورة: px
easing: 'cubic-bezier(.22,1,.36,1)',
directions: ['up', 'start', 'end', 'up'],
```

`start` يدخل من اليسار في LTR ومن اليمين في RTL؛ `end` يعكس ذلك؛ `up` دخول من الأسفل. يمكن ضبط قسم كامل دون تعديل نوع وسمه:

```html
<section data-motion-direction="start">…</section>
```

يمكن تخصيص فقرة أو كارت موجود:

```html
<p data-motion-speed="800" data-motion-delay="100">النص الحالي</p>
<article data-motion-card style="--i: 2">المحتوى الحالي</article>
```

الكروت الموجودة بالخدمات والميزات مشمولة تلقائيًا؛ `data-motion-card` لإضافة كارت آخر للنظام. لكل كارت قيم inline هي `--x` و`--y` بالبكسل و`--r` بالدرجات و`--i` لترتيبه. تُحسب البعثرة في `motionVector` ببذرة ثابتة؛ تغييرها أو تغيير `cardScatter` يعدّل التجميع دون عشوائية متغيرة مع rerender. الصور تستخدم أعماقًا متتابعة 0.55 و0.85 و0.65 و1؛ موضع تعديلها داخل `scrollMotion.js`.

مدة hover ومقدار الرفع والـscale موجودة في `_scroll-motion.scss`. المؤشر الزخرفي وملفاته أزيلت؛ يستخدم الموقع مؤشر النظام الطبيعي.

## حماية SEO والأداء

- الحالة الأساسية ظاهرة. JS يضيف `has-scroll-motion` إلى `<html>` بعد أول تمرير. التحضير يستخدم opacity وtransform فقط، دون display:none أو visibility:hidden.
- الهيـرو وأول قسم والشاشة الأولى مستثناة، مع هامش حماية 80px.
- العناصر البعيدة لا تُنشأ لها طبقات transform عند تحميل الصفحة. ملاحظ تمهيدي بحد 260px يجهّز القريبة، وملاحظ آخر يبدأ الانتقال عند دخولها. الانتقال السريع إلى محتوى ظاهر يكشفه مباشرة.
- كل عنصر يخرج من المراقب عند بدء ظهوره. التركيز بالكيبورد يكشف الكارت فورًا.
- `prefers-reduced-motion` يكشف المحتوى ويلغي التحريك والمراقبين وparallax. تعطيل JavaScript أو غياب IntersectionObserver يترك المحتوى ظاهرًا.
- parallax يستخدم passive scroll listener وRAF واحدًا عند الحاجة، مع تجميع القراءات قبل الكتابات ومراقبة matchMedia للديسكتوب.
- النص الأصلي لا يتغير أثناء التمرير. تغيير HTML هو spans غير دلالية لعناوين محددة وقت SSR؛ نصوص العناوين وترتيب مستوياتها وalt وكتلة metadata مطابقة لما قبل التنفيذ.
- لا يوجد loop دائم أو `will-change` على الصفحة كلها.

## التحقق

نجحت اختبارات المصدر الـ21 وESLint للملفات المعدلة. فحص المتصفح شمل 18 حالة لثلاث صفحات، بلغتين، عند 375 و768 و1440px، مع الظهور مرة واحدة والكيبورد وتقليل الحركة وتعطيل JavaScript. فحص إضافي من أربع حالات تحقّق من تداخل الكروت وزواياها وscale وتوقيتها، ومزامنة كلمات السطر، واختلاف سرعات الصور ومؤشر الديسكتوب.

تقارير الفحص في `homepage-preview.local/scroll-motion-verify/` و`scroll-motion-enhanced/`. تقارير Lighthouse الخام قبل وبعد في `scroll-motion-baseline/` و`scroll-motion-after/` تحت المجلد نفسه.

Lighthouse 13.6، Mobile 375×812، محاكاة الشبكة والمعالج الافتراضية، cache بارد. الرئيسية العربية ثلاث جولات قبل وثلاث بعدها، ونستخدم الوسيط. بقية الصفحات قياس واحد لكل حالة. هذه قياسات محلية وليست بيانات مستخدمين فعليين.
