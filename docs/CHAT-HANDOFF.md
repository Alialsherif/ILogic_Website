- الاسكرول طبيعي؛ لا Lenis ولا اعتراض لعجلة الماوس. المشكلة كانت تقطيع الرسم.
- الشرائط تتحرك عند ظهورها فقط وتتوقف خارج الشاشة وفي التبويب المخفي، مع الحفاظ على زر الإيقاف.
- الخلفيات الكبيرة ثابتة، وParallax خفيف للصور على الكمبيوتر فقط. `will-change` محصور في الحركة الفعالة.
- الانتقال لصفحة بلا hash يعيدها للأعلى فورًا. التنقل للأقسام يحتفظ بالسلاسة واحترام تقليل الحركة.
- قيس تحسن واضح في اختبار محلي CPU 4x؛ التفاصيل في `docs/SCROLL-HEALTH.md`. هذا ليس Lighthouse ولا ضمان FPS لكل الأجهزة.
- أُزيل تأثير الزر الأبيض القديم واللون الإجباري في hover؛ النص والسهم واضحان على أزرار الشركاء والأمان وغيرها.
- أيقونة المتصفح الجديدة `public/ilogic-icon-v2.svg`: أبيض على فحمي، بلا ليموني. `index.html` وSchema يشيران إليها. أُضيف cache header خاص بالأيقونات في `firebase.json` لتجاوز المشكلة القديمة.
- آخر إصلاح: SVG وسائل التواصل أصبح في منتصف دوائره عبر `SocialLinks.module.css`، وأيقونات التواصل 20×20 داخل أهداف لمس 44×44. التأثيرات اللونية للمنصات محفوظة. نُشر هذا الإصلاح بالفعل.
- لا تغيّر الفيديو الخلفي للهيرو إلى المونتاج الكامل: المعتمد حلقة افتتاحية هادئة 8 ثوانٍ من الفيديو الأصلي، بلا controls، مع تباين مقروء. إعداداته في `src/data/heroVideo.json`.

## ملفات وتحقق

- صفحات: `src/pages/{AboutPage,ServicePage,ProjectPage,PartnersPage,Contact}.jsx`.
- النصوص: `src/i18n/{homepage,about,services,projects,partners,partner-form,contact}.{ar,en}.json`، مجمعة في `locale.js`.
- SCSS خاص بكل صفحة؛ `_atelier.scss` يحتوي قواعد الهوية العامة ويأتي بعد بعض ملفات الصفحات، لذا انتبه لترتيب/specificity القواعد.
- `src/entry-server.jsx` و`scripts/write-home-seo.mjs`: HTML عربي prerender للصفحات الست، مع canonical وhreflang وSchema مخصص. الإنجليزية تعمل عبر `?lang=en`؛ لا تدّعِ أن HTML الإنتاج الإنجليزي منفصل prerender حاليًا.
- `npm.cmd run build` يبني ويكتب HTML؛ ثم `firebase.cmd deploy --only hosting --project ai-logika --non-interactive`.
- قد يتطلب Firebase صلاحية خارج sandbox لتحديث ملف تسجيل الدخول في حساب المستخدم. لا تطبع التوكنات ولا تغيّر Billing. صلاحية النشر سبق أن منحها المستخدم.
- قد يفشل الاتصال بالرابط العام داخل sandbox؛ التحقق نجح خارج قيوده، وكل الصفحات الست وfavicon الجديد أعادت HTTP 200.
- اختبارات المصدر: `test:home`, `test:about`, `test:services`, `test:projects`, `test:contact`, `test:partners`, `test:i18n`.
- Browser QA: `node homepage-preview.local/audit.mjs contact-page-review`، ومراحل `projects-page-review`, `about-page-review`, `services-page-review`, `partner-copy-review`, `scroll-motion-timing`, `scroll-health-after`.
- اختُبرت العربية/الإنجليزية عند 375 و768 و1440، مع تحقق من الكيبورد والروابط والـoverflow. اختبارات واتساب تعترض `window.open` ولا ترسل رسائل.
- آخر build وQA للتواصل ومحاذاة الأيقونات نجحا، وآخر deploy نجح. لا تدّعِ درجات Lighthouse نهائية للنسخة الحالية.

وثائق مفيدة: `docs/CONTACT-PAGE.md`, `PROJECTS-PAGE.md`, `SERVICES-PAGE.md`, `PAGE-CHARACTER.md`, `SCROLL-HEALTH.md`, `HERO-VIDEO.md`, `PARTNERS-SEO-REPORT.md`. بعض التقارير القديمة توثّق مراحل سابقة؛ المصدر الحالي والقرارات أعلاه هما المرجع.
