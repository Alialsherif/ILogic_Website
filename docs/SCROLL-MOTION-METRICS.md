# قياس الحركة قبل وبعد

Lighthouse 13.6، Mobile 375×812، محاكاة الشبكة والمعالج الافتراضية، cache بارد. الرئيسية العربية: وسيط ثلاث جولات لكل نسخة. باقي الحالات: جولة واحدة. الأرقام محلية وليست قياسًا ميدانيًا للمستخدمين.

| من نحن | 78 → 75 | 1.69s → 1.62s | 0 → 0 | 100 → 100 | 100 → 100 |
| الشركاء | 60 → 59 | 4.27s → 4.22s | 0 → 0 | 100 → 100 | 100 → 100 |
| الرئيسية الإنجليزية | 53 → 54 | 4.36s → 4.32s | 0 → 0 | 100 → 100 | 97 → 97 |

حجم التحميل الكلي للرئيسية العربية في Lighthouse: 841.5 KB → 738.5 KB.
